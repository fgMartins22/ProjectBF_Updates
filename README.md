# Game Hub (BiGFifas)

Aplicativo de Windows para organizar seus jogos, consultar builds durante a partida e acompanhar as horas jogadas na Steam. Este repositório existe **só para distribuir o instalador** e as atualizações. Não há código-fonte aqui.

## Baixar

1. Abra a página de versões: https://github.com/fgMartins22/ProjectBF_Updates/releases
2. Na versão mais recente (a que **não** está marcada como *Pre-release*), em **Assets**, baixe o arquivo `BiGFifas-Setup-<versão>.exe`.
3. Versões marcadas como *Pre-release* são só de teste. Os arquivos `.yml` e `.blockmap` são usados pelo próprio aplicativo para atualizar. Você não precisa deles.

## Aviso do Windows (esperado)

O instalador ainda não tem assinatura digital. Por isso o Windows pode mostrar a tela azul **"O Windows protegeu o computador"** e o antivírus pode comentar.

1. Clique em **Mais informações**.
2. Clique em **Executar assim mesmo**.

Só instale arquivos baixados **desta página**. O instalador não pede senha de administrador.

## Instalar

1. Abra o `BiGFifas-Setup-<versão>.exe`.
2. Escolha a pasta (ou deixe a sugerida) e conclua. O instalador é por usuário, não pede administrador.
3. Abra o **BiGFifas** pelo atalho da Área de Trabalho ou do Menu Iniciar.

## Conectar a Steam (opcional)

Para ver suas horas, o aplicativo usa uma **chave da Steam que é sua**. Ela fica só no seu computador, cifrada, e nunca vai no instalador. O passo a passo para criar e cadastrar a chave está dentro do aplicativo, em **Configurações > Steam**.

## Atualizar

No aplicativo: **Configurações > Atualizações > Verificar atualizações**. Se houver versão nova, aparece **Atualizar para a versão X**. O aplicativo **só baixa e instala depois do seu clique**, e pede para reiniciar. Ele nunca atualiza sozinho com o programa fechado.

Para a consulta, o aplicativo acessa o GitHub, que pode registrar seu endereço IP e o horário. Nenhum dado seu, sua chave da Steam ou seus jogos são enviados.

Você também pode instalar uma versão nova baixando o instalador aqui e executando-o por cima: seus dados são mantidos.

## Desinstalar

Configurações do Windows > Aplicativos > BiGFifas > Desinstalar (ou pelo botão em Configurações do aplicativo). Por padrão seus dados (builds, histórico, chave) são mantidos; a tela do aplicativo pergunta se você quer apagá-los.

## Problemas

- A atualização falhou: tente de novo mais tarde, ou baixe o instalador novo aqui.
- Aviso do SmartScreen: veja "Aviso do Windows" acima.
